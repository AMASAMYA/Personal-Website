AMASAMYA companion add-on for NVDA

Five keyboard commands for NVDA users who already have the AMASAMYA browser add-on. Jump to the next failure, read the summary, hear the audit result, without leaving your screen reader. Works with Chrome today. Edge and Firefox are untested so far and will land in a later build.

Download v0.2.12 (13 KB)

What you need before you install

  • NVDA 2023.1 or newer. Tested on NVDA 2026.2 on Windows 11.
  • Google Chrome with the AMASAMYA browser add-on already installed. Get it from the Chrome Web Store if you do not have it yet.
  • No separate account, no sign-in. The add-on runs locally and talks to the browser add-on through the DOM.

How to install

  1. Download the file above. Your browser saves it to your Downloads folder as AMASAMYA-NVDA-Addon-v0.2.12.nvda-addon.
  2. Open the NVDA menu with NVDA plus N.
  3. Press T for Tools, then A for Add-on Store. NVDA announces "Add-on Store".
  4. Press Ctrl plus Tab until NVDA announces "Install from external source". Press Enter.
  5. A file dialog opens. Browse to Downloads, select AMASAMYA-NVDA-Addon-v0.2.12.nvda-addon, press Enter.
  6. NVDA warns that the add-on comes from an external source. Press Y for Yes.
  7. NVDA asks to restart. Press Enter to restart NVDA.

Why the warning? NVDA warns on every add-on that did not come from the NVDA Community Add-ons Store. This add-on will go through that store once the beta is stable. Until then, the warning will show on install. You can read the full source at github.com/AMASAMYA/Personal-Website.

What the five keyboard commands do

Every command works two ways. Pick whichever path fits your NVDA setup; both are rebindable from NVDA's Input Gestures dialog under the category "AMASAMYA".

Path 1: single-stroke Alt-modifier

KeystrokeWhat it does
NVDA plus Alt plus ASay whether the AMASAMYA panel is open on this tab, and whether your focus is already inside it.
NVDA plus Alt plus NJump the navigator to the next Critical or Serious failure in the findings table.
NVDA plus Alt plus PJump the navigator to the previous Critical or Serious failure.
NVDA plus Alt plus FRead the How-to-Fix text for the finding currently under the navigator.
NVDA plus Alt plus USpeak the audit summary: failures, warnings, passes, info counts in one line.

Path 2: layer command

Press NVDA plus A. NVDA announces "AMASAMYA layer. A panel, N next, P previous, F fix, U summary." Within two seconds press A, N, P, F, or U to run the matching command. Any other key or the two-second timeout cancels the layer silently.

How to use it with the browser add-on

  1. Open any web page in Chrome.
  2. Press Alt plus Shift plus 1 to open the AMASAMYA side panel.
  3. Activate the Re-run Audit button so the findings table is populated.
  4. Press F6 one or more times until NVDA announces something inside the AMASAMYA panel. The add-on relies on your focus being inside the panel to locate the findings table.
  5. Press NVDA plus Alt plus U to hear the summary, then NVDA plus Alt plus N to walk through failures one at a time.

Known limits in this beta

  • Chrome only in testing. Edge and Firefox should work because the AMASAMYA panel exposes the same accessibility tree in all three, but no live NVDA session has verified either yet.
  • The Fix command (NVDA plus Alt plus F) reports "No How-to-Fix text found. Activate the row with NVDA plus NumpadEnter" when the row is still collapsed. The AMASAMYA panel exposes the fix text only once the row is expanded. A later version will expand the row automatically.
  • Focus must be inside the AMASAMYA panel before the shortcuts can find the table. Chrome does not expose side-panel content through the window handle tree, only through the focused document. Pressing F6 first is a one-time step per tab.
