What you can check

Three kinds of things, one tool, all in your browser. You do not need any special software or a developer's help.

Websites

Paste the address of any page and get back a plain list of the problems on it, with the fix for each. If you can install browser add-ons, you can also check pages you are already looking at by pressing one keyboard shortcut.

Documents

Upload a file. AMASAMYA reads it and tells you where a blind person would get stuck. Works on PDFs, Word, Excel, PowerPoint, EPUB books, and OpenDocument files. The advice you get is specific to the file type, because the fix for a bad PDF is not the same as the fix for a bad PowerPoint.

Mobile apps

A step-by-step checklist you tick off while trying out an iPhone, Android, or wearable app. Each step tells you what to try, which built-in screen reader or setting to use, and what a passing result looks like. When you are done you can download a report.

Optional AI helpers (you bring your own key)

Some accessibility checks only make sense if you can see the screen. If you want AMASAMYA to handle those too, you can plug in a key from OpenAI, Anthropic, or Google. The key is scrambled and kept on your own computer. AMASAMYA has no server that can see it.

See where the keyboard is

Sighted users see a highlight around whatever button they just tabbed to. Blind users cannot verify that highlight is actually visible. This module uses AI to describe the highlight on every button, so a blind tester can check it without asking a colleague.

Check the layout at different sizes

AMASAMYA takes pictures of your page at four common screen widths and uses AI to spot when the page breaks (buttons overlap, text gets cut off, menus fall off the screen).

Watch for silent changes

Some things on a page change without telling anyone (a new message appears, a menu opens, an error shows up). Blind users miss these because their screen reader was not told. This module watches the page and reports every silent change, so you can fix them to announce properly. Runs on your own computer, no AI involved.

Made to be used by blind people

  • Every page and screen works fully with the screen readers used most on Windows, Mac, and Android.
  • Every problem AMASAMYA finds is read out cleanly, in the order you would expect, with the fix included.
  • Reports you download are themselves usable by a blind person reading them, not just PDFs of a screenshot.
  • Nothing you check ever leaves your computer.
  • AMASAMYA's own pages are checked with the same tools you would use on other websites, and pass.

Sign in with Google or with an email and password. Your checks stay on your own computer. If you set up regular checks, the summary of when they ran and what they found syncs to your account so you can see it from any device.
